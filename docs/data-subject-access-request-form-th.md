# แบบฟอร์มคำขอใช้สิทธิ์ของเจ้าของข้อมูลส่วนบุคคล
## Data Subject Access Request Form — ChauatGo

> **สำหรับ:** ลูกค้า ร้านค้า ไรเดอร์ และบุคคลที่ข้อมูลถูกประมวลผลโดย ChauatGo  
> **เวอร์ชัน:** 1.0  
> **วันที่แบบฟอร์ม:** [วัน เดือน ปี]

ChauatGo ใช้แบบฟอร์มนี้เพื่อรับคำขอใช้สิทธิ์ตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล การกรอกข้อมูลเท่าที่จำเป็นจะช่วยให้เรายืนยันตัวตน ค้นหาข้อมูล และติดต่อกลับได้ถูกต้อง

กรุณาส่งแบบฟอร์มพร้อมเอกสารยืนยันตัวตนผ่าน `[อีเมล Privacy/URL แบบฟอร์ม/ที่อยู่]` อย่าส่งรหัสผ่าน รหัส OTP เลขบัตรธนาคารเต็มชุด หรือข้อมูลอ่อนไหวที่ไม่เกี่ยวข้องกับคำขอ

การยื่นคำขอไม่ได้หมายความว่าจะได้รับการอนุมัติทุกกรณี การดำเนินการอาจมีข้อจำกัดหรือข้อยกเว้นตามกฎหมาย และ ChauatGo อาจขอข้อมูลเพิ่มเติมเพื่อยืนยันตัวตนและป้องกันการเปิดเผยข้อมูลให้บุคคลอื่น

# คำแนะนำการใช้งานภายใน

1. จัดเก็บแบบฟอร์มและเอกสารประกอบในพื้นที่จำกัดสิทธิ์ ห้ามเก็บในโฟลเดอร์สาธารณะหรือ Git Repository
2. ใช้ DSAR ID แทนการใส่ชื่อเต็มในชื่อไฟล์หรือแชทภายในเมื่อทำได้
3. อย่าส่งสำเนาเอกสารยืนยันตัวตนผ่านกลุ่มแชททั่วไป
4. บันทึกการขอข้อมูลเพิ่มเติม การตัดสินใจ และการส่งมอบทุกขั้นตอน
5. ปกปิดข้อมูลของบุคคลอื่นก่อนส่งผลลัพธ์
